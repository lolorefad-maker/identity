# آيدينتيتي — Identity · بروتوتايب البورتفوليو

نموذج مقترح لموقع وكالة **آيدينتيتي** (ميديا وتسويق). الفكرة كلها مبنية على الأخطبوط اللي باللوغو:

| صفة الأخطبوط | بالموقع |
|---|---|
| **٨ أذرع** | أخطبوط مرسوم بالكود (`octopus.js`)، أذرعه بتتحرك وبتلحق الماوس |
| **التمويه** | بحلقة الأعمال، الموقع كله والأخطبوط بيلبسوا ألوان كل عميل |
| **الحبر** | شاشة البداية: نقطة حبر بتنزل على ورق وبتغرق الشاشة |

## الأقسام
1. **البداية:** عدّاد، ثم نقطة حبر بتنتشر، ثم الدائرة الكريمية والأخطبوط بيفرد أذرعه، وكلمة «آيدينتيتي» بتنكتب.
2. **الهيرو:** «نصنع الهويّات.»، وIDENTITY عملاقة بالخلفية، والخدمات #01–#04.
3. **شريط العملاء:** أسماء وشعارات العملاء بتمشي لحالها.
4. **الفكرة:** الكلمات بتعبى وحدة وحدة مع السكرول.
5. **ثمانية أذرع = ثمانية خدمات:** أخطبوط كريمي بالنص والخدمات حواليه. مع السكرول الذراع بتمدّ للخدمة الحالية، وشرحها بيطلع بالجنب. بتكبس على أي رقم فبتروح لخدمته.
6. **حلقة الأعمال (Carousel Ring):** ٨ مشاريع بحلقة ثلاثية الأبعاد بتلف مع السكرول، والموقع كله بيتلوّن بألوان كل عميل (التمويه).
7. **نفق المحتوى (Image Tunnel):** طيران لقدّام بنفق من بوستات وستوريز وريلز وبالِتات ألوان، والعدّاد بيوصل لـ ‎+300. بآخر النفق في ضو بيكبر لحد ما يغطي الشاشة وبيطلع اللوغو.
8. **طريقتنا (قسم فاتح):** حبر ← شكل ← هوية، وخط حبر بيرسم حاله، وأرقام بتعدّ لفوق.
9. **التواصل والفوتر:** «خلّينا نصنع هويّتك.» وكلمة IDENTITY مقصوصة من تحت.

عربي/إنجليزي (زر EN / ع)، متجاوب مع الموبايل، وبيحترم إعداد «تقليل الحركة».

## التشغيل
افتح `index.html` مباشرة، أو من جذر المشروع:

```bash
python -m http.server 4300 --directory identity
```

## النشر على Netlify
الموقع ثابت (HTML/CSS/JS) وما بيحتاج build. `netlify.toml` جاهز.
1. على Netlify: **Add new site → Import an existing project → GitHub**، واختار الريبو.
2. اترك **Build command** فاضي و**Publish directory** على `.`، واكبس **Deploy**.
3. أي `git push` بعدها بينزل تلقائيًا على نفس اللينك.

## الملفات
- `index.html` — الصفحة
- `styles.css` — الألوان والتخطيط (`--bg / --ink / --accent` بتتغير وقت التمويه)
- `octopus.js` — الأخطبوط (canvas): الأذرع، الممصات، العيون، الحركة
- `main.js` — البداية، السكرول (GSAP + ScrollTrigger + Lenis)، الحلقة، التمويه، اللغات
- `assets/logo.png` — اللوغو (مقصوص من صورة)

## شو تجريبي لازم يتبدّل
- **المشاريع الثمانية** (قهوة، نور، رَم، زيتون، سَحَر، أطلس، موج، لولو) أسماء وألوان وهمية للعرض. بتتبدّل من مصفوفة `PROJECTS` بـ `main.js`: الاسم، التصنيف، السنة، والألوان الثلاثة.
- **الأرقام** بقسم «طريقتنا» (‎120+ براند، ‎40M+ مشاهدة، 8 خدمات، ‎6+ سنين) و**‎+300 قطعة محتوى** بالنفق كلها تجريبية. أرقام «طريقتنا» بتتبدّل من `data-count` بـ `index.html`، والـ 300 من `renderTunnel` بـ `main.js`.
- **محتوى النفق** (بوستات، ستوريز، ريلز) مرسوم بالكود من ألوان المشاريع. الأحلى تحطوا مكانه صور حقيقية من شغلكم.
- **الخدمات الثمانية** وأوصافها بمصفوفة `SERVICES` بـ `main.js`.
- **رابط واتساب** بقسم التواصل لسا ما إله رقم.
- **اللوغو** مقصوص من سكرين شوت. الأفضل نسخة PNG أو SVG أصلية.
